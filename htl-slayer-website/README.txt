# HTL-Slayer – Projektwebseite

## Dateien
- `index.html` – Inhalt der Webseite
- `style.css` – Gestaltung und responsives Layout

## Vor der Veröffentlichung
1. Im Bereich **Impressum** die Platzhalter durch die von der HTL bzw. Lehrperson vorgegebenen Angaben ersetzen.
2. Prüfen, ob alle Gruppenmitglieder mit der öffentlichen Nennung ihrer Namen einverstanden sind.
3. Nur eigene oder ausdrücklich freigegebene Bilder, Logos, Musik und Schriftarten verwenden. In dieser Version werden keine fremden Spielgrafiken verwendet.
4. Die Webseite lokal durch Öffnen von `index.html` testen.

## Veröffentlichung mit GitHub Pages
1. Auf GitHub ein neues Repository erstellen, z. B. `htl-slayer`.
2. `index.html` und `style.css` in das Repository hochladen (direkt in den Hauptordner).
3. Im Repository **Settings → Pages** öffnen.
4. Unter **Build and deployment** `Deploy from a branch` wählen.
5. Als Branch `main` und Ordner `/ (root)` auswählen und speichern.
6. Nach dem Deployment zeigt GitHub Pages die öffentliche URL an.

Hinweis: Die Webseite ist vorbereitet, aber noch nicht online gestellt. Dafür müssen die Dateien in euer GitHub-Repository hochgeladen und Pages aktiviert werden.
